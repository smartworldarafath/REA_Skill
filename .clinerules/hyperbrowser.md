# Hyperbrowser MCP (Cline)

## Directive
When scraping complex client-side single-page applications (React, Vue, WebGL) or requiring full-site crawling:
- Use Hyperbrowser MCP (https://github.com/hyperbrowserai/mcp):
  - `crawl_page` — crawl dynamic JavaScript SPAs and extract rendered DOMs
  - `extract_data` — parse visual elements and complex web apps into structured JSON
  - `record_session` — record interactive browser traces for test and audit evidence
- Pair with REA to analyze dynamically injected client scripts and WebSocket streams.
