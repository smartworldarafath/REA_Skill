# Bright Data MCP (Windsurf)

## Directive
When target web endpoints block standard requests with Cloudflare, DataDome, or anti-bot protections:
- Use Bright Data MCP (https://github.com/brightdata/brightdata-mcp) via `@brightdata/mcp`:
  - `scrape_url` — automated CAPTCHA solving and protected page content extraction
  - `search_engine` — real-time Google/Bing SERP structured queries
  - `extract_structured_data` — direct conversion of web pages to JSON models
- Pair with REA and security audits to inspect protected endpoints without IP bans.
