Methodology

5-Phase Web Security Audit

A structured, reproducible auditing sequence executed automatically by the agent.

PHASE 01

HTTP Security Headers

Inspects HSTS preload, Content-Security-Policy (CSP), X-Frame-Options against clickjacking, and permissive CORS wildcards.

PHASE 02

Frontend Bundle Inspection

Scans bundled client chunks for leaked private environment variables, service-role tokens, or unredacted payment webhooks.

PHASE 03

Database RLS & Anon Keys

Verifies Row Level Security (RLS) policies on Supabase/Postgres tables to confirm public anonymous keys cannot bypass data privacy.

PHASE 04

API Routes & Rate Limiting

Maps exposed endpoint surfaces, authentication middleware requirements, and verifies brute-force / DDoS rate limiting.

PHASE 05

Webhook Verification

Audits external payment (Stripe, LemonSqueezy) and authentication (Clerk) webhooks for mandatory HMAC signature verification.

Unified .mcp.json Architecture

Connects reverse engineering and browser engines directly into your agent's tool space.

.mcp.json (Root Configuration) 
{
  "mcpServers": {
    "rea": {
      "command": "cmd.exe",
      "args": ["/c", "npx", "-y", "rea-agents@latest"]
    },
    "playwright": {
      "command": "cmd.exe",
      "args": ["/c", "npx", "-y", "@playwright/mcp@latest"]
    },
    "hyperbrowser": {
      "command": "cmd.exe",
      "args": ["/c", "npx", "-y", "hyperbrowser-mcp@latest"],
      "env": {
        "HYPERBROWSER_API_KEY": "${HYPERBROWSER_API_KEY}"
      }
    },
    "brightdata": {
      "command": "cmd.exe",
      "args": ["/c", "npx", "-y", "@brightdata/mcp@latest"],
      "env": {
        "BRIGHTDATA_API_KEY": "${BRIGHTDATA_API_KEY}"
      }
    }
  }
}
